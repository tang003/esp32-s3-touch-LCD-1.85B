# 1.85B 圆屏蓝牙更新固件

此功能适用于 **Waveshare ESP32-S3-Touch-LCD-1.85B** 与支持固件更新的 MOTO GPS iPhone App。更新文件是此仓库为 **1.85B** 编译的 `moto_gps_esp32.bin`，不是安装到 iPhone 的 `.ipa`。

## 第一次启用

旧固件只有一个应用分区，也没有蓝牙更新入口。因此第一次仍需用 USB 将新版 **bootloader、分区表和应用** 一起刷入；只刷应用 `.bin` 不能启用蓝牙更新。首次刷写前，按 [固件说明](../platforms/esp32/README.md#备份和刷写)核对板型、容量并保留已有的整片备份。**不要执行 `erase-flash`**；新版分区表保留原有地图存储区的起始位置。

之后的应用固件更新可以在 iPhone 上完成，无需把圆屏再接到电脑。蓝牙更新不使用导航网关，也不要求圆屏连接 Wi-Fi。

## 每次更新

1. 在电脑上用 **1.85B / 16 MB** 配置编译固件。可选的应用镜像位于 `platforms/esp32/build/moto_gps_esp32.bin`。不要选 `bootloader.bin`、`partition-table.bin`、整片备份或其他板型的镜像。
2. 将这个 `.bin` 放到 iPhone 的“文件”App，例如通过隔空投送、iCloud Drive 或可信的文件传输方式。
3. 让圆屏有充足电量或接稳定电源，打开 MOTO GPS 并连接圆屏。在“我的圆屏”中选择固件更新，再从“文件”选取 `.bin`。
4. 停车操作，让 App 保持前台、手机靠近圆屏，等待传输完成。圆屏会重启并重新连接。更新中不要关机、离开蓝牙范围或退出 App。

App 会拒绝明显不是本项目应用镜像的文件，以及超过更新分区容量的文件；设备也会核对长度、传输 SHA-256 和 ESP 应用镜像有效性。SHA-256 用于发现传输损坏，**不是发布者签名**。第一版仅作为个人测试功能，公开销售前还需做固件签名、安全启动和更新权限设计。

若蓝牙中断或文件校验失败，旧应用分区应继续可启动；重新连接后从头再试。若更新后无法正常启动，ESP-IDF 的回滚机制会尝试恢复上一版。首次 USB 分区迁移及回滚仍需在实机验证；保留整片备份以便通过 USB 恢复。
